# Nền tảng AI VietTriTong — Nền tảng sáng tạo nội dung truyền thông xã hội AI cho thị trường Việt Nam

**Kiếm tiền · Xuất bản · Tương tác · Sáng tạo — Tất cả trong một nền tảng.**

---

Nền tảng AI VietTriTong giúp các thương hiệu và doanh nghiệp xây dựng, phân phối và kiếm tiền từ nội dung với **tự động hóa AI** trên các nền tảng phổ biến nhất tại Việt Nam.

Nền tảng hỗ trợ: TikTok, YouTube, Instagram, Facebook, Twitter (X), LinkedIn, Pinterest, Threads, Xiaohongshu, Douyin, Bilibili, Kuaishou

---

## Tính năng chính

### 🎨 Sáng tạo — Tác nhân sáng tạo nội dung AI

Chỉ cần nói với Tác nhân những gì bạn cần — nó xử lý mọi thứ từ ý tưởng đến sản phẩm hoàn chỉnh.

- **Video AI**: Seedance 2.0, Grok Video, Gemini Video
- **Hình ảnh & Văn bản**: Tạo hình ảnh AI với nhiều mô hình
- **Tạo hàng loạt**: Tạo nhiều nội dung cùng lúc

### 📢 Xuất bản — Tác nhân xuất bản nội dung

Phân phối nội dung đến 12+ nền tảng lớn chỉ với một cú nhấp chuột.

- **Đa nền tảng**: TikTok, YouTube, Facebook, Instagram, Threads, X (Twitter), Pinterest, LinkedIn
- **Lịch xuất bản**: Lên lịch và điều phối nội dung
- **Bản địa hóa tiếng Việt**: Lồng tiếng Việt + phụ đề

### 💬 Tương tác — Tác nhân tương tác nội dung

Tự động hóa tương tác trên các nền tảng.

- **Hành động tự động**: Tự động thích, đánh dấu, theo dõi
- **Trả lời thông minh AI**: Tạo phản hồi có mục tiêu cho mỗi bình luận
- **Giám sát thương hiệu**: Theo dõi đề cập thương hiệu theo thời gian thực

### 💰 Kiếm tiền — Kiếm tiền từ nội dung (Sắp ra mắt)

- **Chợ nội dung**: Thương hiệu đăng nhiệm vụ quảng bá, người sáng tạo nhận việc
- **Thanh toán CPS/CPE/CPM**: Nhiều mô hình thanh toán
- **Xác minh AI**: Tự động xác minh mức độ phù hợp của nội dung

## Bắt đầu nhanh

🌐 **Trang web**: [https://ai.yuezhitong.com](https://ai.yuezhitong.com)

### Docker

```bash
git clone https://github.com/008486club-sketch/VietTriTong-AI.git
cd VietTriTong-AI
docker compose up -d
```

### Phát triển

```bash
cd project/aitoearn-backend && pnpm install && pnpm nx serve aitoearn-ai
cd project/aitoearn-web && pnpm install && pnpm run dev
```
